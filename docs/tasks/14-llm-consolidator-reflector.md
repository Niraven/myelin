# Task: LLM Consolidator & Reflector

**Status:** Complete
**Priority:** P1
**Assignee:** builder
**Dependencies:** 13-schema-learning
**Domain:** development/mlops

## Goal

Replace placeholder template text in consolidation summaries and reflections with **actual informative content** generated by a lightweight LLM. The consolidator produces episode summaries with real analysis. The reflector generates multi-level insights (episode, session, cross-domain).

## Why

Phase 1-2 used template strings like `"Reflection generated from {n} recent episodes"` — technically functional but useless for human reading or downstream decision-making. LLM-generated summaries turn Myelin's internal processing into actionable intelligence.

## Architecture

```
Consolidator:
  Episode batch → extract entities, tags, outcomes
               → LLM prompt: "Summarize what happened and what was learned"
               → Output: structured summary with key entities, success analysis, tags

Reflector:
  Consolidated summaries → multi-level analysis
                        → Level 1: episode-level patterns
                        → Level 2: session-level trends
                        → Level 3: cross-domain linkage
                        → Output: insight with entity density, confidence, classification
```

## Key Design Decisions

1. **Lightweight LLM only** — not for every memory. Only runs during sleep for consolidated batches. Default model configurable, defaults to cheap/fast.
2. **Structured output** — summaries include: `entities`, `key_insights`, `success`, `tags`, `confidence`. Reflections include: `level`, `entity_density`, `trends`, `classifications` (mastery/exploration/error-recovery).
3. **Entity density tracking** — how many unique entities per reflection. Higher density = richer insight. Tracked as a quality metric.
4. **No hallucination risk** — the LLM is given only the consolidated text and asked to summarize/reflect on it. No free generation.
