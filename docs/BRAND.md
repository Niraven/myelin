# Myelin Brand

## Positioning

Primary line:

> mem0 remembers. Myelin learns.

Short description:

> Agents should not relearn workflows.

Long description:

> Myelin watches AI agents work, discovers repeated action patterns, promotes them into reusable procedures, and improves confidence with feedback.

## Visual Identity

The logo is a myelin-sheath-inspired ring around a signal path. It should feel technical, local-first, and research-grounded. Avoid generic brain icons, neural-network webs, and decorative gradients.

## Voice

- Lead with proof, not hype.
- Say “procedural learning” and “agent acceleration” more than “memory.”
- Be explicit about local-first and no LLM requirement for core operations.
- Avoid benchmark claims unless they are freshly verified.
- Treat Hermes as the first flagship integration, not the whole market.

## Greek-Tech Direction

The stronger visual direction is a Greek-tech sigil: a golden myelin sheath with a subtle ouroboros curve around a teal signal path. It gives the project more character than a plain terminal dashboard while staying connected to the name.

Keep the serpent reference subtle. Myelin should not become a mascot, fantasy snake, or security-brand cliché.
